# KeySight
Projeto de FastAPI com front end em vue.js para de um site que procura key de jogo em todas as palataformas 

Rastreador de Preços de Jogos Digitais

Um agregador pessoal para monitorar quedas de preços de chaves de jogos em múltiplas plataformas e lojas digitais.



Backend (FastAPI): Integração com APIs de lojas (como Steam) e uso de BackgroundTasks (ou Celery) para verificar descontos periodicamente de forma assíncrona.

Frontend (Vue.js): Lista de desejos personalizável, ordenação dinâmica por maior percentual de desconto e gráficos de histórico de preços usando bibliotecas de visualização (como Vue-ChartJS).

Dashboard de Analytics e Business Intelligence

Uma aplicação estilo mini-BI para consumir, transformar e visualizar métricas próprias (podem ser estatísticas de jogos competitivos, despesas mensais ou progresso de estudos).



Backend (FastAPI): Endpoints otimizados para consultas analíticas complexas, servindo agregações de dados prontas para consumo (aplicando conceitos práticos de modelagem SQL).

Frontend (Vue.js): Interface rica com tabelas dinâmicas, filtros de período de tempo interativos e múltiplos painéis de dados.
